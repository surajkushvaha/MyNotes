Step by step
Sign up with Google

Open apinex.bond/register. Tick the box I accept the Privacy Policy and Terms of Use, then click Continue with Google and pick your Google account.

The sign up card, 18 Nov 2026

Tip The card says it takes a personal @gmail.com account only, so a work or school Google address will not get in. Use a Gmail account you are fine linking to a third-party service.

If it fails Nothing happens when you click? Tick the terms box first, then click Continue with Google again.

Check your daily allowance and Opus access

When the reel was made, APInex advertised a daily allowance that required a one-time $5 top-up. Check Billing for the offer on your account before adding funds.

Open the APInex model catalog and find Claude 4.6 Opus. APInex currently labels it Subscription only. Open Pricing and confirm the plan duration and token allowance before buying.

Tip Check the model's token weight in the catalog. It affects how much of your plan allowance a request uses.

If it fails If Opus returns an access error, check that your subscription is active and the model is included. Step 6 shows how to check the account allowance.

Create and copy your key

Log in at apinex.bond/login, open API Keys (apinex.bond/keys) and create a key. It starts with sk-apx. Copy the full key right away: APInex shows it once and never again.

Keep it somewhere safe, like your password manager or a private note. Anyone with the key can spend your balance.

Tip Logged in, API Keys → Setup shows APInex's own setup steps for Claude Code, Cursor and other tools with your key filled in. Keep the key out of ChatGPT or Claude. Enter it only on your own device when following the setup steps.

If it fails Lost the key? Create a new one in API Keys. If it was exposed, revoke the old one there too.

Questions
Is it really free?

APInex lists a $0 per-token rate for this model and requires an active subscription to access it. Check the model catalog before signing up.

What is a token?

A token is a small piece of text, on average about three quarters of an English word. Both what you send and what the model writes back count. A chat message is a few hundred to a few thousand tokens. Claude Code reads your files as it works, so longer coding sessions may consume more of your allowance.

Is this Anthropic?

No. APInex is a third-party service that resells access to models from several companies. It is not affiliated with Anthropic, and Anthropic says it does not endorse, maintain or audit third-party gateways like this one. You cannot check which model actually answers or what happens to your prompts on the way. So keep private data, client data, passwords, keys and code you are not allowed to share off it. Use it for side projects, learning and experiments.

What if it stops working?

Free offers like this can change or end any day. Check apinex.bond/status first. The reliable fallback is the official Claude API at platform.claude.com (Claude Opus 4.6 costs $5 input and $25 output per 1M tokens there), or simply your own Claude plan: follow the reset steps from the Claude Code prompt to return to your normal login.

What are the limits?

The token allowance and request limit depend on your plan. The prompt in step 6 walks you through checking your account allowance.
